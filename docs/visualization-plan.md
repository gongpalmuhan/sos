# 대시보드·이슈 트래커 시각화 방향

## 사용자 선호

- 대시보드와 이슈 트래커에 D3.js, Chart.js 같은 데이터 시각화 라이브러리를 활용한다.
- 현재 저장소에는 앱 코드나 패키지 설정이 없으므로, 이 문서는 구현 단계에서 참고할 방향을 기록한다.
- 제품 범위와 지표 정의는 [MVP 제품 계약](mvp-scope.md)을 따른다. 아래 후보는 별도의 MVP 필수 기능을 추가하지 않는다.

## 라이브러리 선택 제안

| 용도 | 우선 검토 | 이유 |
| --- | --- | --- |
| 막대·선·도넛 등 기본 통계 차트 | Chart.js | 기본 차트 유형과 설정을 제공하므로 표준 차트를 빠르게 구성하기 좋다. |
| 이슈·PR 관계, 상세 타임라인 등 맞춤 시각화 | D3.js | 스케일, 도형, 상호작용을 조합해 표현을 세밀하게 제어할 수 있다. |

기본 통계부터 Chart.js로 구현하고, 맞춤 시각화가 필요한 화면에서 D3.js 도입을 결정하는 방안을 권장한다. 두 라이브러리를 처음부터 모두 설치하는 것으로 확정하지 않는다.

## SOS 적용 후보

| 화면 | 표현 후보 | 데이터·범위 조건 |
| --- | --- | --- |
| 개인 대시보드 | 연결한 PR의 상태별 건수 막대 차트 | `open`, `merged`, `closed_without_merge`를 구분한다. 개인 기록으로 제공하며 PR 수 경쟁이나 순위로 사용하지 않는다. |
| 개인 대시보드 | 저장소별 평균 첫 리뷰 시간 비교 | 산출 기준, 대상 기간, 표본 범위, 확인 시점을 함께 표시한다. 세부 계산 규칙은 MVP 문서의 후속 결정 항목을 따른다. |
| 이슈 트래커 | 이슈 선택부터 PR 연결·리뷰·병합까지의 타임라인 | 실제로 기록되거나 원문에서 확인된 시점만 표시한다. 사용자 표시와 GitHub에서 확인한 사건을 구분한다. 단순한 단계 표시는 일반 UI로도 구현할 수 있다. |
| 맥락 리포트 확장 | 관련 이슈·PR 관계 그래프 | 원문으로 확인된 관계만 연결한다. MVP에서는 원문 링크 목록으로 시작하고, 그래프는 필요성을 검토한 뒤 도입한다. |

## 구현 시 기준

- 차트 옆에 핵심 수치와 텍스트 또는 표를 제공하고, 색상이나 마우스 호버에만 정보를 의존하지 않는다. Chart.js의 canvas에는 접근 가능한 이름과 대체 설명을 제공한다.
- 로딩, 데이터 없음, 조회 실패를 구분하고, 확인되지 않은 값은 0으로 대체하지 않는다.
- 차트와 목록은 같은 필터·기간·집계 기준을 사용한다. 기간별 추이는 해당 기간의 이력이 확보된 뒤 제공한다.
- 프레임워크, 연동 패키지, 버전은 앱 기술 스택을 정할 때 선택한다.
